# Bingo Web App

A simple web-based bingo game built with ASP.NET Core.

## Features
- Generate random bingo cards (5x5 grid with FREE space in center)
- Mark numbers as they're called
- Automatic win detection (rows, columns, diagonals)
- Clean, responsive UI

## How to Run
1. Install .NET 8.0 SDK or later
2. Clone this repository
3. Run `dotnet run` in the project directory
4. Open browser to `https://localhost:5001` or `http://localhost:5000`
